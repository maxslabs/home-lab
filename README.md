# Home Lab – IT Support & Networking Fundamentals

## Overview

This repository documents my home lab environment built using VirtualBox and Kali Linux.

The purpose of this lab is to develop foundational skills in:
- IT support
- Networking
- System troubleshooting

through hands-on practice in a controlled virtual environment.

This project represents my ongoing learning journey as I transition into IT support and cybersecurity.

---

## Lab Environment

| Component | Details |
|---|---|
| Host Machine | Personal PC/Laptop |
| Virtualisation Software | Oracle VirtualBox |
| Operating System | Kali Linux (Virtual Machine) |
| Network Mode | NAT / Bridged |

---

## Skills Practiced

In this lab, I focused on:

- Virtual machine setup and configuration
- Linux system navigation and terminal usage
- Network interface inspection and configuration
- Basic connectivity testing using networking tools
- Understanding how systems communicate within a network
