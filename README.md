Home Lab – IT Support & Networking Fundamentals

Overview

This repository documents my home lab environment built using VirtualBox and Kali Linux. The purpose of this lab is to develop foundational skills in IT support, networking, and system troubleshooting through hands-on practice in a controlled virtual environment.

This project represents my ongoing learning journey as I transition into IT support and cybersecurity.

Lab Environment
Host Machine: Personal PC/Laptop
Virtualisation Software: Oracle VirtualBox
Operating System: Kali Linux (Virtual Machine)
Network Mode: NAT / Bridged (adjust if needed)
Skills Practiced

In this lab, I have been focusing on:

Virtual machine setup and configuration
Linux system navigation and basic terminal usage
Network interface inspection and configuration
Basic connectivity testing using standard networking tools
Understanding how systems communicate within a network
Tools Used
VirtualBox
Kali Linux
Terminal / Command Line Tools
Networking utilities (ip, ping, nslookup, nmap)
Key Learning Outcomes

Through this lab, I have gained practical understanding of:

How virtual machines simulate real IT environments
How IP addressing and network interfaces function in Linux
How DNS resolution works in practice
How basic network troubleshooting is performed using command-line tools
How IT support teams use similar tools for diagnostics
